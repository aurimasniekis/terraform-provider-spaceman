# spaceman_event_fleet_scope_grant (Resource)

Lets a space's event subscriptions use `ingest_own_scope = "fleet"": ingest the run dialog events (`evt.spaceman.fleet.run.dialog_detected` and `_cleared`, automation depth 0, identifying fields only) of **every** space (`/event-fleet-scope-grants/{space_id}`, SpaceMan ADR-0106). This is installation administration: **the provider's token must be an operator-level token** (`system:write`; API tokens skip step-up), a space's own permissions never suffice, and it is never reachable through SpaceMan MCP or Telegram. Destroying the grant revokes it at once: the space's fleet-scoped subscriptions then filter other spaces' events, and updating them is refused until their `ingest_own_scope` is back to `space`. Needs SpaceMan 0.1.17 or later.

## Example Usage

```terraform
# One operations space may watch every space's run dialogs. Only an installation administrator can give this grant, so the
# provider needs an operator-level token (an API token with system:write). Without the grant, ingest_own_scope = "fleet"
# is refused with 403; revoking it later makes the subscription filter other spaces' events.
resource "spaceman_event_fleet_scope_grant" "ops" {
  space_id = spaceman_space.ops.id
  reason   = "Operations space that watches every run for stuck dialogs"
}

resource "spaceman_event_subscription" "all_dialogs" {
  space_id         = spaceman_space.ops.id
  name             = "all run dialogs"
  connection_id    = spaceman_event_connection.pulse.id
  ingest_own       = true
  ingest_own_scope = "fleet"
  custom = jsonencode({
    subject = "evt.spaceman.fleet.run.dialog_detected"
    title   = "A run in any space is stopped at a dialog"
  })

  depends_on = [spaceman_event_fleet_scope_grant.ops]
}
```

## Schema

### Required

- `space_id` (String) The space that receives the grant (not archived). Changing it replaces the grant. Also the import ID.

### Optional

- `reason` (String) Why the space may ingest every space's run dialog events (at most 500 characters); recorded on the grant and in the audit log. Changing it replaces the reason in place.

### Read-Only

- `fleet_subscriptions` (Number) How many of the space's subscriptions currently use `ingest_own_scope = "fleet"` (read-only).
- `granted_at` (String) When the grant was first given (RFC 3339).
- `granted_by` (String) Who gave the grant.

## Import

Import is supported using the following syntax:

```shell
# <space_id>
terraform import spaceman_event_fleet_scope_grant.ops spc_01j0000000000000000000000
```

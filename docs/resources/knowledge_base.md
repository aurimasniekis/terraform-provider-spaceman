# spaceman_knowledge_base (Resource)

A knowledge base configuration of a space (`/spaces/{id}/kbs`). Sessions, requests and proposals are runtime state and are not managed. SpaceMan has no API to delete a knowledge base: destroying the resource disables it and removes it from Terraform's state.

## Example Usage

```terraform
resource "spaceman_knowledge_base" "docs" {
  space_id     = spaceman_space.payments.id
  slug         = "docs"
  name         = "Payments docs"
  repo         = "kb/payments-docs"
  space_role   = spaceman_space_role.kb.name # a role whose template is of kind kb
  validator    = ["python3", "tools/kb.py", "check"]
  write_policy = "review"
}
```

## Schema

### Required

- `name` (String) Display name.
- `repo` (String) Repository folder inside the space (relative), for example `spaceman_space_repository.kb.path`. A folder no space repository uses yet is added to the space's repositories (role `kb`, clone policy `manual`); declare it as a `spaceman_space_repository` to manage it.
- `slug` (String) Identifier in the space (2-31 characters). Fixed after creation.
- `space_id` (String) The space.
- `space_role` (String) A space role whose template is of kind `kb`; sessions run as it.

### Optional

- `allowed_roles` (List of String) Requester roles admitted to sessions; `*` (default) admits every role.
- `base_branch` (String) Where accepted knowledge lives (default `main`).
- `description` (String) Description.
- `enabled` (Boolean) Whether the knowledge base accepts requests (default `true`).
- `entry_instructions` (String) Instructions every session starts with.
- `idle_sleep_seconds` (Number) Idle time before a session sleeps (60-86400, default 900).
- `max_sessions` (Number) Sessions running at once (1-16, default 2).
- `request_timeout_seconds` (Number) Request timeout (60-86400, default 1800).
- `session_ttl_seconds` (Number) Session lifetime (3600-2592000, default 604800).
- `validator` (List of String) Command run on a proposal before it is accepted, e.g. `["python3", "tools/kb.py", "check"]`.
- `write_policy` (String) `read_only`, `review` (default) or `serialized`.

### Read-Only

- `id` (String) The knowledge base ID.

## Import

Import is supported using the following syntax:

```shell
# <space_id>/<kb_id>
terraform import spaceman_knowledge_base.docs spc_01j0000000000000000000000/kbr_01j0000000000000000000000
```

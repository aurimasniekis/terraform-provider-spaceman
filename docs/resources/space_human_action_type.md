# spaceman_space_human_action_type (Resource)

Enables a human-action type in a space (`PUT/DELETE /spaces/{id}/human-types/{type}`), following its latest version or pinned to one, optionally as a variant with its own label and defaults. Destroying it stops new actions of the type in the space; outstanding actions are unaffected.

## Example Usage

```terraform
resource "spaceman_space_human_action_type" "review" {
  space_id = spaceman_space.payments.id
  type_id  = spaceman_human_action_type.design_review.id
  label    = "Payments design review"
}
```

## Schema

### Required

- `space_id` (String) The space.
- `type_id` (String) The type (`hty_…` ID).

### Optional

- `default_expiry_minutes` (Number) Overrides the version's default expiry in this space (minutes).
- `default_priority` (String) Overrides the version's default priority in this space.
- `label` (String) The space's name for the type (a variant). Left out, the type's name is used.
- `version_pin` (String) A published version ID to pin; empty follows the latest version.

### Read-Only

- `id` (String) `<space_id>/<type_id>`.
- `version_id` (String) The version the space uses now.
- `version_number` (Number) Its number.

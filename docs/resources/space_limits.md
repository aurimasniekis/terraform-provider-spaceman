# spaceman_space_limits (Resource)

A space's limit overrides (`GET/PUT /spaces/{id}/limits`, SM-LIMIT-001). Terraform owns only the limits the configuration sets: an override set in the UI for another limit is kept and is not drift, and removing an attribute clears that override (the installation default applies again). Destroying the resource clears the overrides it owns. Updates use `If-Match` with the version read at refresh. Lowering a limit never stops running work, except `max_concurrent_runs` with `on_lower = "stop"`. Use one resource per space. The effective values are in the `spaceman_space_limits` data source; the top-level task limit is in `spaceman_space_queue_policy`.

## Example Usage

```terraform
resource "spaceman_space_limits" "payments" {
  space_id = spaceman_space.payments.id

  # Only these limits are Terraform's; overrides of other limits set in the UI are kept.
  max_concurrent_runs    = 4
  max_tool_calls_per_run = 2000
  task_deadline_minutes  = 240
  budget_tokens_24h      = 20000000
  budget_warn_percent    = 75
  on_lower               = "drain"
}
```

## Schema

### Required

- `space_id` (String) The space.

### Optional

- `budget_cost_cents_24h` (Number) Harness cost estimates of runs started in the last 24 hours, in US cents (0: no budget). Estimates, reported late. Unset: not managed (the installation default or an override set elsewhere applies).
- `budget_tokens_24h` (Number) Reported tokens of runs started in the last 24 hours (0: no budget). Usage-based and reported late: never a hard limit. Unset: not managed (the installation default or an override set elsewhere applies).
- `budget_tokens_per_run` (Number) Reported tokens of one run (0: no budget; warning only, never stops a run). Unset: not managed (the installation default or an override set elsewhere applies).
- `budget_warn_percent` (Number) Share of a budget at which operators are warned (1-100). Unset: not managed (the installation default or an override set elsewhere applies).
- `export_max_bytes` (Number) Size of one space export archive (1 MiB-64 GiB); a larger export is refused. Unset: not managed (the installation default or an override set elsewhere applies).
- `ingest_per_minute` (Number) Events one subscription ingests per minute; the rest waits in the stream (1-60000). Unset: not managed (the installation default or an override set elsewhere applies).
- `max_concurrent_runs` (Number) Worker and diagnostic runs active in the space at once (1-256). Unset: not managed (the installation default or an override set elsewhere applies).
- `max_human_pending` (Number) Open human actions in the space (1-5000). Unset: not managed (the installation default or an override set elsewhere applies).
- `max_human_pending_per_run` (Number) Open human actions one agent run asked (1-500). Unset: not managed (the installation default or an override set elsewhere applies).
- `max_kb_sessions` (Number) Active KB support sessions in the space, across its knowledge bases (1-64; each KB also has its own `max_sessions`). Unset: not managed (the installation default or an override set elsewhere applies).
- `max_tool_calls_per_run` (Number) SpaceMan and MCP gateway tool calls of one run (0-1000000; 0: no limit). Unset: not managed (the installation default or an override set elsewhere applies).
- `on_lower` (String) What lowering `max_concurrent_runs` does to running runs: `drain` (SpaceMan's default) lets them finish, `stop` stops the newest runs beyond the new limit. Left out, the value in SpaceMan is kept; removing it from the configuration resets it to `drain`.
- `recording_quota_bytes` (Number) Compressed size of one run's terminal recording on the node (1 MiB-64 GiB); new runs get the new size. Unset: not managed (the installation default or an override set elsewhere applies).
- `retention_attachments_days` (Number) Days an attachment is kept once every item using it is finished (0-36500; 0: kept); never deleted while an open item uses it. Needs `retention:write`. Unset: not managed (the installation default or an override set elsewhere applies).
- `retention_human_actions_days` (Number) Days a resolved, cancelled or expired human action is kept (0-36500; 0: kept); kept while open work refers to it. Needs `retention:write`. Unset: not managed (the installation default or an override set elsewhere applies).
- `retention_recordings_days` (Number) Days central keeps an ended run's terminal recording (0-36500; 0: kept). Changing it needs `retention:write` (space admins); a shorter period deletes older recordings in the next daily retention pass. Unset: not managed (the installation default or an override set elsewhere applies).
- `retention_transcripts_days` (Number) Days central keeps a run's stored native transcript (0-36500; 0: kept). Needs `retention:write`. Unset: not managed (the installation default or an override set elsewhere applies).
- `storage_quota_bytes` (Number) Attachment bytes stored for the space (1 MiB-1 TiB). Unset: not managed (the installation default or an override set elsewhere applies).
- `support_depth` (Number) How deep support may nest (1-3; 1: a KB session cannot ask a knowledge base). Unset: not managed (the installation default or an override set elsewhere applies).
- `task_deadline_minutes` (Number) How long a top-level task may run before control and the operators are told (0-43200; 0: none; never stops a task). Unset: not managed (the installation default or an override set elsewhere applies).

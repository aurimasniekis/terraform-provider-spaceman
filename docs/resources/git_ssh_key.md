# spaceman_git_ssh_key (Resource)

A shared Git SSH key (`/git-ssh-keys`, SpaceMan ADR-0058). SpaceMan generates it and keeps the private half: neither Terraform nor agents ever see it. Add `public_key` to the Git account the listed spaces may clone with (a read-only machine user is safest: a key on a person's account can also push), then point repositories at it with `spaceman_space_repository.git_key_id`. Destroying it fails while a repository uses it.

## Example Usage

```terraform
# One key for many private repositories: SpaceMan generates it and keeps the private half; agents never receive it and
# Terraform only sees the public half. Add it to a read-only machine user (a key on a person's account can also push to
# everything that person can), here with the integrations/github provider while authenticated as that user.
resource "spaceman_git_ssh_key" "github_bot" {
  name        = "github-bot"
  description = "Read-only machine user for the payments repositories"
  spaces      = [spaceman_space.payments.id]
}

resource "github_user_ssh_key" "spaceman" {
  title = "SpaceMan"
  key   = spaceman_git_ssh_key.github_bot.public_key
}

resource "spaceman_space_repository" "settlements" {
  space_id   = spaceman_space.payments.id
  name       = "settlements"
  url        = "git@github.com:example-org/settlements.git"
  git_key_id = spaceman_git_ssh_key.github_bot.id
}
```

## Schema

### Required

- `name` (String) Unique name: lowercase letters, digits, `.`, `_` or `-`.

### Optional

- `all_spaces` (Boolean) Let every space use the key. Default `false`: only `spaces`.
- `description` (String) Description.
- `key_version` (Number) Change this number to rotate the key: SpaceMan replaces it at once, so update the account's SSH key in the same apply.
- `spaces` (Set of String) IDs of the spaces that may use the key (ignored with `all_spaces`).

### Read-Only

- `fingerprint` (String) The key's SHA256 fingerprint.
- `id` (String) The key ID (`gky_…`).
- `public_key` (String) The public half (authorized_keys format), for the Git account's SSH key or a deploy key.

## Import

Import is supported using the following syntax:

```shell
# <key_id>
terraform import spaceman_git_ssh_key.github_bot gky_01j0000000000000000000000
```

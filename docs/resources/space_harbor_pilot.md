# spaceman_space_harbor_pilot (Resource)

A space's Harbor Pilot opt-in (`/spaces/{id}/harbor-pilot`, SpaceMan ADR-0060). For the listed harnesses each run gets its own short-lived Harbor Pilot token, bound to the space, the run and the project, in place of a harness account: there is no fallback to a direct account. Enabling needs `spaceman_harbor_pilot_connection`. Needs `space_config:write`; setting or changing `project_id` (who pays) needs `account:write`. Destroying the resource removes the settings, and the space's runs use their accounts again. Import with the space ID.

## Example Usage

```terraform
resource "spaceman_space_harbor_pilot" "payments" {
  space_id   = spaceman_space.payments.id
  enabled    = true
  project_id = "prj_payments" # a project the connection's client binding allows

  harnesses                    = ["claude-code", "codex"]
  ttl_seconds                  = 43200 # 12 h run tokens
  on_budget_status_unavailable = "proceed"
  allowed_model_aliases        = ["fleet/default"]

  # Enabling needs the connection.
  depends_on = [spaceman_harbor_pilot_connection.this]
}
```

## Schema

### Required

- `enabled` (Boolean) Whether the space's runs of the listed harnesses go through Harbor Pilot.
- `space_id` (String) The space.

### Optional

- `allowed_model_aliases` (Set of String) Model aliases the space's runs may use; empty (default): any model the binding's plan routes.
- `harnesses` (Set of String) Harness kinds routed through Harbor Pilot; the others keep their accounts. Default `claude-code` and `codex`.
- `on_budget_status_unavailable` (String) What a launch does when Harbor Pilot budget status can't be read: `proceed` (default; the gateway still enforces its budgets) or `refuse`.
- `project_id` (String) The Harbor Pilot project the space's runs are charged to (required when `enabled`). It must be the connection binding's project or one of its `allowed_project_ids`. Removing it from the configuration keeps the stored project.
- `ttl_seconds` (Number) Lifetime of a run's token, 900 to 604800 seconds (default 86400). A run that outlives it loses model access.

### Read-Only

- `connected` (Boolean) Whether a Harbor Pilot connection exists.
- `id` (String) The space ID.

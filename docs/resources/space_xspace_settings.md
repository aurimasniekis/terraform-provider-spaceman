# spaceman_space_xspace_settings (Resource)

A space's cross-space settings (`GET/PUT /spaces/{id}/xspace/settings`, ADR-0038): the profile peers allowed to discover the space see, the deepest request chain it accepts and how many requests its control may send per hour. What a space accepts from and may send to each peer is `spaceman_xspace_peer`. Every space has settings (SpaceMan's defaults until saved), so destroying the resource resets them to the defaults.

## Example Usage

```terraform
resource "spaceman_space_xspace_settings" "payments" {
  space_id              = spaceman_space.payments.id
  profile               = "Owns the payment API and the refunds flow. Ask about charge states and refunds."
  max_depth             = 2
  max_outgoing_per_hour = 30
}
```

## Schema

### Required

- `space_id` (String) The space.

### Optional

- `max_depth` (Number) Requests deeper than this in a chain are refused here (1-8, default 3).
- `max_outgoing_per_hour` (Number) Requests this space's control may send per hour, to every peer together (1-1000, default 60).
- `profile` (String) What peers allowed to discover this space see about it, written for agents (at most 2000 characters).

### Read-Only

- `id` (String) The space ID.

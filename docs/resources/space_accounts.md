# spaceman_space_accounts (Resource)

The accounts a space's runs may use (`GET/PUT /spaces/{id}/accounts`). This resource owns the space's whole binding set: bindings added in the UI show as drift. At most one default per harness. Destroying it removes every binding.

## Example Usage

```terraform
resource "spaceman_space_accounts" "payments" {
  space_id = spaceman_space.payments.id
  binding = [
    { account_id = spaceman_account.claude.id, default = true },
    { account_id = spaceman_account.openai.id },
  ]
}
```

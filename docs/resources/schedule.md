# spaceman_schedule (Resource)

A space schedule (`/spaces/{id}/schedules`, ADR-0036): at each cron or interval occurrence it creates an inbox item or a ready task in the space. Occurrences, their outcomes and what they created are runtime state and are not managed. A changed timing restarts the schedule from now; occurrences before the change are not treated as missed. Destroying the resource deletes the schedule; what it already created stays.

## Example Usage

```terraform
# An inbox item every weekday morning in Vilnius.
resource "spaceman_schedule" "triage" {
  space_id = spaceman_space.payments.id
  name     = "morning-triage"
  kind     = "cron"
  cron     = "0 9 * * 1-5"
  timezone = "Europe/Vilnius"
  target   = "inbox"
  title    = "Triage open pull requests"
  body     = "Look at the pull requests opened since yesterday and plan the day."
  priority = "high"
}

# A ready task every six hours, counted from a fixed anchor.
resource "spaceman_schedule" "dependency_audit" {
  space_id         = spaceman_space.payments.id
  name             = "dependency-audit"
  kind             = "interval"
  interval_seconds = 21600
  anchor           = "2026-01-01T00:00:00Z"
  missed           = "run_once"
  target           = "task"
  title            = "Audit dependencies"
  assignee_role    = "implementor"
}
```

## Schema

### Required

- `kind` (String) `cron` or `interval`.
- `name` (String) Unique name in the space (at most 80 characters).
- `space_id` (String) The space (not archived).
- `target` (String) `inbox` (an inbox item) or `task` (a ready task).
- `title` (String) Title of the item or task (at most 200 characters).

### Optional

- `anchor` (String) `interval`: RFC 3339 time occurrences are counted from (anchor + n × interval). Left out, SpaceMan sets it to the creation time and keeps it while `kind` and `interval_seconds` stay the same.
- `assignee_role` (String) `task` only: the role the task is assigned to; set it to `""` before changing `target` to `inbox`.
- `body` (String) Markdown: the inbox item body or the task objective.
- `catch_up_max` (Number) `catch_up`: how many missed occurrences run at most (1-100, default 3).
- `cron` (String) `cron`: a five-field expression or `@hourly`, `@daily`, `@weekly`, `@monthly`, `@yearly`, in `timezone` (`@every` and `TZ=` are refused). Empty for interval schedules.
- `description` (String) Description.
- `enabled` (Boolean) Whether occurrences run (default `true`).
- `interval_seconds` (Number) `interval`: seconds between occurrences (60 s to 366 days). 0 for cron schedules.
- `missed` (String) Occurrences missed while central was stopped or the space archived: `skip` (default), `run_once` or `catch_up`.
- `priority` (String) Inbox urgency or task priority: `low`, `normal` (default), `high` or `urgent`.
- `skip_if_open` (Boolean) Skip an occurrence while what the previous one created is still open (default `true`).
- `timezone` (String) IANA time zone of the cron expression (default `UTC`).

### Read-Only

- `id` (String) The schedule ID.

## Import

Import is supported using the following syntax:

```shell
# <space_id>/<schedule_id>
terraform import spaceman_schedule.triage spc_01j0000000000000000000000/sch_01j0000000000000000000000
```

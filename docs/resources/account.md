# spaceman_account (Resource)

A harness account (`/accounts`): a sealed credential that runs of a harness use. The secret is write-only: it is sent to SpaceMan, sealed there and never returned, and Terraform never stores it (requires Terraform 1.11 or later).

## Example Usage

```terraform
variable "anthropic_api_key" {
  type      = string
  sensitive = true
  ephemeral = true # never stored in a plan or state
}

resource "spaceman_account" "claude" {
  name        = "claude-team"
  kind        = "anthropic_api_key"
  description = "Team key for Claude Code runs"
  metadata    = { owner = "platform" }

  secret_wo         = var.anthropic_api_key
  secret_wo_version = 1 # bump to rotate
}
```

## Schema

### Required

- `kind` (String) `claude_oauth_token`, `anthropic_api_key` or `openai_api_key`. Changing it replaces the account (its bindings go with it).
- `name` (String) Unique name (at most 63 characters).
- `secret_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The credential (write-only). Sent on create and whenever `secret_wo_version` changes.

### Optional

- `description` (String) Description.
- `enabled` (Boolean) Whether runs may use the account (default `true`).
- `metadata` (Map of String) Free-form labels.
- `secret_wo_version` (Number) Change this number to send `secret_wo` again (rotation). Terraform never stores the write-only value, so it cannot see when the value itself changes.

### Read-Only

- `harness` (String) The harness the kind is for (`claude-code` or `codex`).
- `id` (String) The account ID.
- `secret_rotated_at` (String) When the secret was last set (RFC 3339).
- `secret_version` (Number) SpaceMan's count of stored secrets (increments on every rotation).

## Import

Import is supported using the following syntax:

```shell
terraform import spaceman_account.claude acc_01j0000000000000000000000
```

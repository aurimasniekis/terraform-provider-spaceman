# spaceman_mcp_server (Resource)

An upstream MCP server of the gateway (`/mcp-servers`). Header values (e.g. `Authorization`) are write-only: sealed by SpaceMan, never returned and never stored by Terraform (requires Terraform 1.11 or later). Agents see the server's tools only through a `spaceman_mcp_grant`. Deleting the server removes its grants.

## Example Usage

```terraform
variable "tracker_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "spaceman_mcp_server" "tracker" {
  slug  = "tracker"
  name  = "Ticket tracker"
  url   = "https://tracker.example.com/mcp"
  tools = ["list_tickets", "get_ticket", "comment"]

  headers_wo         = { Authorization = "Bearer ${var.tracker_token}" }
  headers_wo_version = 1
}
```

## Schema

### Required

- `name` (String) Display name.
- `slug` (String) Namespace of the server's tools (`<slug>__<tool>`). Changing it replaces the server (and drops its grants).
- `url` (String) Streamable HTTP endpoint; `https` unless `allow_private`.

### Optional

- `allow_private` (Boolean) Allow loopback and private addresses and plain http (link-local stays refused). Default `false`.
- `call_timeout_ms` (Number) Timeout of one tool call (server default when left out).
- `description` (String) Description.
- `enabled` (Boolean) Whether the gateway offers the server (default `true`).
- `headers_wo` (Map of String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Request headers such as `Authorization` (write-only). Sent on create and whenever `headers_wo_version` changes; an empty or missing map then clears the stored headers.
- `headers_wo_version` (Number) Change this number to send `headers_wo` again (rotation). Terraform never stores the write-only value, so it cannot see when the value itself changes.
- `max_concurrency` (Number) Calls in flight to this server across all runs (server default when left out).
- `max_result_bytes` (Number) Largest tool result passed to an agent (server default when left out).
- `tools` (Set of String) Upstream tools offered to agents; empty offers every tool.

### Read-Only

- `header_names` (List of String) Names of the stored headers (values are never returned).
- `headers_version` (Number) Increments whenever the stored headers change.
- `id` (String) The server ID.

## Import

Import is supported using the following syntax:

```shell
terraform import spaceman_mcp_server.tracker mcp_01j0000000000000000000000
```

# spaceman_human_action_type (Resource)

A custom human-action type (`/human-types`) with versioned request and response schemas. The content attributes describe the latest published version; changing them publishes the next version (outstanding actions keep theirs). Requests and responses are runtime state and are never managed. SpaceMan has no API to rename or delete a type: identifying fields are fixed and destroying the resource only removes it from Terraform's state.

## Example Usage

```terraform
resource "spaceman_human_action_type" "design_review" {
  slug = "design-review"
  name = "Design review"
  request_schema = jsonencode({
    type       = "object"
    properties = { doc = { type = "string", title = "Design document" } }
    required   = ["doc"]
  })
  response_schema  = jsonencode({ type = "object", properties = { notes = { type = "string" } } })
  outcomes         = ["approved", "changes_requested"]
  default_priority = "high"
}
```

## Schema

### Required

- `name` (String) Display name. Fixed after creation.
- `slug` (String) Unique identifier. Fixed after creation.

### Optional

- `default_expiry_minutes` (Number) Default expiry in minutes (0: none).
- `default_priority` (String) `low`, `normal`, `high` or `urgent`.
- `description` (String) Description. Fixed after creation.
- `notes` (String) Notes recorded with the published version.
- `outcomes` (List of String) How a person can finish it, e.g. `["done", "declined"]`.
- `request_schema` (String) JSON Schema 2020-12 of the request (root `{"type": "object"}`), as JSON (use `jsonencode`).
- `response_schema` (String) JSON Schema 2020-12 of the response data, as JSON.
- `ui` (String) Safe form metadata (`{order, fields: {field: {label, help, widget, placeholder}}}`), as JSON.

### Read-Only

- `id` (String) The type ID.
- `latest_version` (Number) Number of the latest published version.
- `latest_version_id` (String) ID of the latest published version (use it to pin).

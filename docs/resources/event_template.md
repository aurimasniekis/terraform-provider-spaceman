# spaceman_event_template (Resource)

A custom event template (`/event-templates`). `definition` and `notes` describe the latest published version; changing them publishes the next immutable version (`PUT /event-templates/{id}/draft`, `POST /event-template-versions/{id}/publish`). Subscriptions that follow the latest version move to it when its subject stays the same; the others are reported. SpaceMan has no API to rename or delete a template: identifying fields are fixed and destroying the resource only removes it from Terraform's state.

## Example Usage

```terraform
resource "spaceman_event_template" "deploy_failed" {
  slug = "deploy-failed"
  name = "Failed deploys"
  definition = jsonencode({
    subject   = "evt.deploy.{{vars.env}}.>"
    variables = [{ name = "env", required = true, example = "prod" }]
    filters   = [{ path = "data.status", op = "eq", value = "failed" }]
    title     = "Deploy to {{vars.env}} failed"
    body      = "{{data.message}}"
    urgency   = "high"
  })
}
```

## Schema

### Required

- `definition` (String) The definition as JSON (use `jsonencode`): `subject`, `variables`, `filters`, `input_schema`, `title`, `body`, `instructions`, `correlation`, `urgency`. Formatting and key order never cause a diff.
- `name` (String) Display name. Fixed after creation.
- `slug` (String) Unique identifier. Fixed after creation.

### Optional

- `description` (String) Description. Fixed after creation.
- `notes` (String) Notes recorded with the published version.

### Read-Only

- `id` (String) The template ID.
- `latest_version` (Number) Number of the latest published version.
- `latest_version_id` (String) ID of the latest published version (subscribe to it).

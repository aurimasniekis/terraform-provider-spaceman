# spaceman_user_identity (Resource)

An expected OIDC sign-in identity linked to a user (`POST/DELETE /users/{id}/identities`), so a pre-provisioned user signs in through that provider. Identities cannot be edited: any change replaces the link. Unlinking (destroy) drops the user's SSO-mapped grants and ends their sessions. Single-use link invitations are one-time secrets and are not managed.

## Example Usage

```terraform
# Ada signs in through Porch; the subject is her Porch user ID.
resource "spaceman_user_identity" "ada_porch" {
  user_id     = spaceman_user.ada.id
  provider_id = spaceman_oidc_provider.porch.id
  subject     = "u_01j0000000000000000000000"
}
```

## Schema

### Required

- `provider_id` (String) The OIDC provider (`spaceman_oidc_provider`).
- `subject` (String) The provider's stable `sub` claim (with Porch, the `u_…` user ID; never an email).
- `user_id` (String) The user (`usr_…`).

### Read-Only

- `id` (String) `<user_id>/<provider_id>/<subject>`.
- `issuer` (String) The provider's issuer the identity is recorded under.

# spaceman_telegram_settings (Resource)

The policy and defaults of central's Telegram bot (`/telegram/settings`, SpaceMan ADR-0083): who may link, lifetimes, send and inbound limits, and each link's notification defaults. There is one set per central. Every attribute is optional: only the ones you set are stored, a value left out follows SpaceMan's built-in default (taking an attribute out of the configuration puts it back to the default), and the effective values are always shown. The first plan after an import shows an update: applying it stores the configuration and records which values are configured. Out-of-range values are refused at plan time. Changes reach the running bot without a restart. A user's own notification preferences and time zone are theirs: they override these defaults and are not managed here. The bot itself (`spaceman_telegram_bot`) is separate, and the Bot API's address is not settable here: it stays in central's configuration file. Destroying the resource resets every value to its built-in default. Needs `system:write` and a step-up. Import with the ID `telegram-settings`.

## Example Usage

```terraform
# Every attribute is optional: only what you set is stored, and an attribute left out (or taken out later) follows
# SpaceMan's built-in default, which the values below are.
resource "spaceman_telegram_settings" "this" {
  # Who may link, and for how long.
  link_default_max_role = "operator" # or "viewer": the most a Telegram session may do in any space
  link_allow_admin_cap  = false
  link_sso_grants       = false
  link_reconfirm_days   = 90
  links_per_user        = 1
  link_code_ttl_seconds = 600

  # Mini App lifetimes.
  init_data_max_age_seconds        = 300
  miniapp_session_idle_seconds     = 900
  miniapp_session_absolute_seconds = 3600

  # Whether a new link starts with a topic per space.
  topics_mode_default = false

  # Outbound limits, at or below Telegram's published limits.
  send_limits = {
    global_per_second = 25
    chat_per_second   = 1
    chat_burst        = 3
    group_per_minute  = 20
    queue_total       = 5000
    queue_per_chat    = 50
  }

  # Inbound abuse limits.
  inbound_limits = {
    actions_per_minute   = 30
    actions_burst        = 10
    inbox_items_per_hour = 60
    downloads_per_hour   = 50
    updates_per_second   = 20
  }

  # What each link notifies about until its user changes it. Times are wall-clock times in each
  # user's own time zone.
  notification_defaults = {
    new_actions       = true
    min_priority      = "normal"
    assigned_to_me    = true
    escalations       = true
    reminders         = "push" # push, digest or off
    clarifications    = true
    operator_messages = true
    inbox_items       = "digest"
    tasks_in_review   = "digest"
    failed_runs       = "digest"
    digest            = true
    digest_time       = "09:00"
    threads           = "auto" # auto, on or off
    quiet_hours       = true
    quiet_hours_start = "23:00"
    quiet_hours_end   = "08:00"
  }
}
```

## Schema

### Optional

- `inbound_limits` (Attributes) Inbound abuse limits: what linked users can make central do. Excess gets a single "slow down" answer. (see [below for nested schema](#nestedatt--inbound_limits))
- `init_data_max_age_seconds` (Number) The oldest Mini App `initData` accepted for a session exchange, in seconds. Default 300. (60 to 3600)
- `link_allow_admin_cap` (Boolean) Whether a link may be given the admin cap at all. Default `false`.
- `link_code_ttl_seconds` (Number) Lifetime of a link code, in seconds. Default 600. (120 to 1800)
- `link_default_max_role` (String) The cap a new link gets: its Telegram session never has more than this role in any space, whatever the user's grants: `viewer` or `operator`. Default `operator`.
- `link_reconfirm_days` (Number) Days after which a link must be confirmed again from the web. Default 90. (7 to 365)
- `link_sso_grants` (Boolean) Whether a link confirmed from an SSO session also carries the user's SSO-mapped grants, until that session's absolute expiry. Default `false`.
- `links_per_user` (Number) Telegram accounts one SpaceMan user may link. Default 1. (1 to 3)
- `miniapp_session_absolute_seconds` (Number) A Mini App session ends this long after the exchange, whatever its use, in seconds; at least `miniapp_session_idle_seconds`. Default 3600. (900 to 43200)
- `miniapp_session_idle_seconds` (Number) A Mini App session ends after this long without a request, in seconds. Default 900. (300 to 3600)
- `notification_defaults` (Attributes) What each link notifies about until its user changes it. Digest and quiet-hour times are wall-clock times in each user's own time zone. (see [below for nested schema](#nestedatt--notification_defaults))
- `send_limits` (Attributes) Outbound rate limits and queue bounds, each at or below Telegram's published limits. (see [below for nested schema](#nestedatt--send_limits))
- `topics_mode_default` (Boolean) Whether a new link starts in topics mode (a topic per space in the private chat). Default `false`.

### Read-Only

- `id` (String) Always `telegram-settings` (the settings are a singleton).

- `tasks_in_review` (String) Tasks entering review: `push`, `digest` or `off`. Default `digest`.
- `threads` (String) The chat layout of a link: `auto`, `on` or `off`. A user can override it for their own link. Default `auto`.

### Nested Schema for `send_limits`

### Optional

- `chat_per_second` (schema.Float64Attribute) Messages per second to one private chat. Default 1. (above 0, at most 1)

## Import

Import is supported using the following syntax:

```shell
# The settings are a singleton: their import ID is always telegram-settings.
terraform import spaceman_telegram_settings.this telegram-settings
```

# spaceman_harbor_pilot_connection (Resource)

Central's connection to a [Harbor Pilot](https://aurimasniekis.github.io/go-harbor-pilot/) gateway (`/harbor-pilot/connection`, SpaceMan ADR-0060). There is one per central. Spaces opt in with `spaceman_space_harbor_pilot`; their runs then get a short-lived child token minted from the parent token instead of a harness account.

Both tokens are write-only: sealed by SpaceMan, never returned and never stored by Terraform (requires Terraform 1.11 or later). They fit Harbor Pilot's ephemeral `harborpilot_gateway_token` and `harborpilot_service_principal_token` resources. Every write is validated against Harbor Pilot (a probe mint, revoked at once), so the gateway must be reachable from central. Destroying the connection is refused while a space routes runs through Harbor Pilot or run tokens are live. Needs `account:write`. Import with the ID `harbor-pilot`.

## Example Usage

```terraform
# Tokens issued by Harbor Pilot. Pass them as ephemeral values (or from Harbor Pilot's own ephemeral
# harborpilot_gateway_token and harborpilot_service_principal_token resources): Terraform never stores them.
variable "harbor_pilot_parent_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

variable "harbor_pilot_service_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "spaceman_harbor_pilot_connection" "this" {
  base_url = "https://harbor-pilot.example.com"

  # A gateway credential with gateway:invoke, gateway:models and tokens:mint.
  parent_token_wo         = var.harbor_pilot_parent_token
  parent_token_wo_version = 1

  # Optional: a service-principal token with usage.read and config.read (budget status, project checks).
  service_token_wo         = var.harbor_pilot_service_token
  service_token_wo_version = 1
}
```

## Schema

### Required

- `base_url` (String) The gateway origin central calls to mint and revoke run tokens and read budget status, e.g. `https://harbor-pilot.example.com`. `https` unless the host is loopback or `allow_insecure_http` is set. Changing it sends both tokens again: SpaceMan sends stored tokens only to the address they were entered for.
- `parent_token_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) A Harbor Pilot gateway credential (`hpk_…`) with `gateway:invoke`, `gateway:models` and `tokens:mint` (write-only). Sent on create, whenever `parent_token_wo_version` changes and whenever the gateway address changes.

### Optional

- `allow_insecure_http` (Boolean) Allow plain `http` (tests and trusted local networks only: every token then crosses the network in clear text). Default `false`.
- `parent_token_wo_version` (Number) Change this number to send `parent_token_wo` again (rotation). Terraform never stores the write-only value, so it cannot see when the value itself changes.
- `run_base_url` (String) The origin runs reach the gateway on, when it differs from `base_url` (for example when central reaches it on loopback). It needs `https` (no loopback exemption) unless `allow_insecure_http` is set. Empty: `base_url`.
- `service_token_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) A Harbor Pilot service-principal token (`hpa_…`) with `usage.read` and `config.read` (write-only), for budget status and project checks. Sent on create, whenever `service_token_wo_version` changes and whenever the gateway address changes. Removed only when `service_token_wo_version` changes with no `service_token_wo` configured: an address change without it, while SpaceMan holds a service token, fails (add `service_token_wo`, or change `service_token_wo_version` to remove the token).
- `service_token_wo_version` (Number) Change this number to send `service_token_wo` again (rotation). Terraform never stores the write-only value, so it cannot see when the value itself changes.

### Read-Only

- `binding_id` (String) The parent token's Harbor Pilot client binding, learnt when SpaceMan validated the connection.
- `connection_id` (String) SpaceMan's ID of the connection.
- `has_parent_token` (Boolean) Whether SpaceMan holds a parent token.
- `has_service_token` (Boolean) Whether SpaceMan holds a service-principal token.
- `id` (String) Always `harbor-pilot` (the connection is a singleton).
- `parent_expires_at` (String) When the parent token expires (RFC 3339), if it does.
- `parent_token_version` (Number) SpaceMan's counter of parent token writes.
- `service_token_version` (Number) SpaceMan's counter of service-principal token writes and removals.

## Import

Import is supported using the following syntax:

```shell
# The connection is a singleton: its import ID is always harbor-pilot.
terraform import spaceman_harbor_pilot_connection.this harbor-pilot
```

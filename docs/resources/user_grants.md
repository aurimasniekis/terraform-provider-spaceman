# spaceman_user_grants (Resource)

A user's manual role grants (`PUT /users/{id}/grants`). This resource owns the user's whole manual grant set: a grant added or removed in the UI shows as drift. Grants that come from OIDC group mappings (`spaceman_oidc_group_mapping`, SSO sessions only) are not part of it and are never touched. SpaceMan ends the user's sessions when their grants change, keeps at least one enabled global administrator, and makes local accounts with operator or admin grants enroll TOTP. Before writing, the provider re-reads the grants and refuses when they differ from the last refresh. Destroying the resource removes every manual grant.

## Example Usage

```terraform
resource "spaceman_user_grants" "ada" {
  user_id = spaceman_user.ada.id
  grant = [
    { role = "viewer", domain = "*" },
    { role = "operator", domain = spaceman_space.payments.id },
  ]
}
```

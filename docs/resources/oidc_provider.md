# spaceman_oidc_provider (Resource)

An OpenID Connect sign-in provider (`/oidc/providers`). The client secret is write-only: sealed by SpaceMan, never returned and never stored by Terraform (requires Terraform 1.11 or later). Discovery runs at the first sign-in, not when the provider is saved. Deleting it removes its group mappings and linked identities.

## Example Usage

```terraform
variable "porch_client_secret" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "spaceman_oidc_provider" "porch" {
  slug         = "porch"
  display_name = "Porch"
  issuer       = "https://porch.example.com"
  client_id    = "spaceman"
  groups_claim = "porch.groups"
  provisioning = "jit"
  jit          = { groups = ["spaceman-users"] }
  enabled      = true

  client_secret_wo         = var.porch_client_secret
  client_secret_wo_version = 1
}
```

## Schema

### Required

- `client_id` (String) The OAuth client ID. Changing it clears the test-login evidence.
- `display_name` (String) Name on the sign-in page.
- `issuer` (String) The issuer URL. Changing it clears the test-login evidence.
- `slug` (String) Identifier used in sign-in URLs.

### Optional

- `acr_values` (List of String) ACR values requested for step-up.
- `allow_cross_origin_endpoints` (Boolean) Allow discovery to name endpoints on other origins than the issuer (default `false`).
- `allow_private_network` (Boolean) Allow the issuer's endpoints on private addresses (default `false`).
- `ca_bundle_pem` (String) PEM certificates trusted for the issuer's endpoints.
- `client_secret_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The client secret (write-only). Sent on create and whenever `client_secret_wo_version` changes; empty or left out then removes the stored secret (public clients).
- `client_secret_wo_version` (Number) Change this number to send `client_secret_wo` again (rotation). Terraform never stores the write-only value, so it cannot see when the value itself changes.
- `enabled` (Boolean) Whether the provider is offered at sign-in (default `false`).
- `end_session_enabled` (Boolean) RP-initiated logout: signing out of an SSO session also offers the provider's `end_session_endpoint` when its discovery document advertises one (default `false`). Register `<public_url>/login` as a post-logout redirect URI at the provider.
- `groups_claim` (String) Claim holding the user's groups; a dotted path walks nested objects (Porch: `porch.groups`).
- `jit` (Attributes) Restrictions of just-in-time provisioning. (see [below for nested schema](#nestedatt--jit))
- `provisioning` (String) `preprovisioned` (default: only linked users sign in) or `jit` (create users on first sign-in).
- `scopes` (List of String) Requested scopes (default `openid profile email`).
- `stepup_fallback` (String) Step-up for SSO sessions when the IdP cannot re-authenticate: `none` (default) or `local_totp`.

### Read-Only

- `has_client_secret` (Boolean) Whether a client secret is stored.
- `id` (String) The provider ID.

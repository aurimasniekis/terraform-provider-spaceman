# spaceman_space_role (Resource)

A role configured in a space (`PUT/DELETE /spaces/{id}/roles/{name}`): a role template with space-specific overrides. Non-empty fields override the template's; changes apply to later launches.

## Example Usage

```terraform
resource "spaceman_space_role" "implementor" {
  space_id     = spaceman_space.payments.id
  name         = "implementor-backend"
  template_id  = spaceman_role_template.worker.id
  model        = "claude-sonnet-4-5"
  instructions = "Work in small, reviewed steps."
  skills = [
    { skill_id = spaceman_skill.release_notes.id },
  ]
}
```

- `space_id` (String) The space.
- `template_id` (String) The role template (`rtp_…`).

### Optional

- `model` (String) Model overriding the profile's.
- `profile_id` (String) Harness profile overriding the template's.
- `prompt_id` (String) Prompt overriding the template's.
- `prompt_pin` (String) A published version of `prompt_id`; empty follows the latest version.
- `settings` (Map of String) Harness settings overriding the template's.
- `skills` (Attributes List) Skills added to the template's; a pin here wins. (see [below for nested schema](#nestedatt--skills))

### Read-Only

- `id` (String) `<space_id>/<name>`.
- `revision` (Number) Increments on every change of the role.

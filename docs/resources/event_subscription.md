# spaceman_event_subscription (Resource)

An event subscription of a space (`/spaces/{id}/subscriptions`): a template version (or a custom definition) bound to a Pulse connection. With `follow = "latest"` SpaceMan moves the subscription to newly published template versions; that move is not drift. Deliveries, quarantine and the consumer's position are runtime state and are not managed.

## Example Usage

```terraform
data "spaceman_event_template" "github_issues" {
  slug = "github-issue"
}

resource "spaceman_event_subscription" "issues" {
  space_id            = spaceman_space.payments.id
  name                = "payments issues"
  connection_id       = spaceman_event_connection.pulse.id
  template_version_id = data.spaceman_event_template.github_issues.latest_version_id
  follow              = "latest"
  vars                = { account_key = "acme", repository = "acme/payments" }
}
```

## Schema

### Required

- `connection_id` (String) The Pulse connection. Changing it replaces the subscription.
- `name` (String) Name, unique in the space (at most 80 characters).
- `space_id` (String) The space.

### Optional

- `custom` (String) A custom definition as JSON instead of a template version (cannot follow).
- `delivery` (String) `durable` (default): a JetStream durable consumer, acknowledged after the inbox commit, redelivered and replayable. `core`: a plain NATS Core subscription for sources that publish without JetStream. **Non-durable**: no replay, no redelivery, no cursor (leave `start` out), and messages published while SpaceMan is disconnected are lost. Changing it replaces the subscription.
- `enabled` (Boolean) Whether the subscription consumes (default `true`).
- `follow` (String) `pinned` (default) or `latest` (move to newly published versions that keep the subject).
- `start` (Attributes) Where the consumer starts: applied on create, and on an update whenever this value changes (recreating the consumer; required when the subject changes). Anything but `new` replays history. Left out: `new` (no history). (see [below for nested schema](#nestedatt--start))
- `template_version_id` (String) A published template version. With `follow = "latest"` this is the starting version; SpaceMan moves it forward.
- `vars` (Map of String) Variable values. Only the configured variables are compared: defaults SpaceMan fills in are not drift.

### Read-Only

- `consumer` (String) The JetStream consumer (`<client_id>_<durable>`).
- `durable` (String) The durable name the Pulse operator must grant.
- `grant` (String) The Pulse grant the subscription needs.
- `id` (String) The subscription ID.
- `subject` (String) The effective Pulse filter.
- `template_id` (String) The template of `template_version_id`.

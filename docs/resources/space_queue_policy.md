# spaceman_space_queue_policy (Resource)

A space's queue policy (`PUT /spaces/{id}/queue/policy`), which holds the top-level task limit of the limits model. SpaceMan has no `If-Match` for it: before writing, the provider re-reads the policy and refuses when it differs from the last refresh. It is read from the queue listing (`GET /spaces/{id}/tasks`). SpaceMan has no API to remove a stored policy: destroying the resource keeps the current policy and removes it from Terraform's state.

## Example Usage

```terraform
resource "spaceman_space_queue_policy" "payments" {
  space_id            = spaceman_space.payments.id
  max_top_level_tasks = 2
  incident_insertion  = "top"
  incident_preempts   = true
}
```

## Schema

### Required

- `space_id` (String) The space.

### Optional

- `escalation_reorders` (Boolean) Escalation may move a task to the top; otherwise it only raises priority (default `false`).
- `incident_insertion` (String) Where new incident tasks go: `top` (default) or `priority`.
- `incident_preempts` (Boolean) A new incident returns running ordinary top-level tasks to ready (default `false`).
- `max_top_level_tasks` (Number) Top-level tasks that may run at once (1-20; default: the installation's `limits.max_top_level_tasks`).

### Read-Only

- `id` (String) The space ID.

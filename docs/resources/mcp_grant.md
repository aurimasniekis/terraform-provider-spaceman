# spaceman_mcp_grant (Resource)

Grants an MCP server to a space role (`POST/DELETE /mcp-servers/{id}/grants`). Grants cannot be edited: any change revokes the grant and adds a new one. A revoked grant refuses the affected runs' next call.

## Example Usage

```terraform
resource "spaceman_mcp_grant" "tracker_read" {
  server_id = spaceman_mcp_server.tracker.id
  space_id  = spaceman_space.payments.id
  role      = "implementor-backend"
  tools     = ["list_tickets", "get_ticket"]
}
```

## Schema

### Required

- `server_id` (String) The MCP server.
- `space_id` (String) The space.

### Optional

- `role` (String) A space role name, or `*` (default) for every role.
- `tools` (Set of String) Subset of the server's tools; empty grants all of them.

### Read-Only

- `id` (String) The grant ID.

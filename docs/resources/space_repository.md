# spaceman_space_repository (Resource)

A repository of a space (`/spaces/{id}/repositories`, ADR-0044): its folder in the space folder, clone URL, default branch, role and clone policy. The space's node clones it (with an `auto` policy as soon as it holds the space's lease) using its own Git authentication: the URL never carries credentials, and SpaceMan stores none. Writer worktrees, knowledge bases and relocation use the configured repositories. The node's report (remote, heads, last fetch, changes, unpushed commits, worktrees) and syncs are runtime state and are not managed. Destroying the resource removes the repository from the space's list only: its folder on the node and the upstream repository stay; a repository a knowledge base uses cannot be removed.

## Example Usage

```terraform
# The API service, cloned by the space's node as soon as it holds the lease. The node's own Git authentication (SSH key,
# credential helper, Hallpass Git role) is used; the URL carries no credentials.
resource "spaceman_space_repository" "api" {
  space_id       = spaceman_space.payments.id
  name           = "api"
  path           = "repos/api"
  url            = "git@github.com:example-org/payments-api.git"
  default_branch = "main"
  description    = "Settlement and refunds API"
}

# A knowledge base's repository, cloned the first time a KB session needs it.
resource "spaceman_space_repository" "kb" {
  space_id     = spaceman_space.payments.id
  name         = "payments-kb"
  path         = "repos/payments-kb"
  url          = "https://github.com/example-org/payments-kb.git"
  role         = "kb"
  clone_policy = "on_demand"
}
```

## Schema

### Required

- `name` (String) Unique in the space: 1-63 lowercase letters, digits, `.`, `_` or `-`. Changing it replaces the repository.
- `space_id` (String) The space (not archived).

### Optional

- `clone_policy` (String) `auto` (default with a URL: cloned while the node holds the space's lease), `on_demand` (cloned when a run needs it or on a sync) or `manual` (default without a URL: never cloned by SpaceMan).
- `default_branch` (String) The branch the node checks out and reports on (default `main`).
- `description` (String) Description.
- `path` (String) Folder relative to the space folder (default the name), for example `repos/api`; not in `instances/`, `worktrees/`, `work/` or `dreams/`. Changing it replaces the repository (the old folder stays on the node).
- `role` (String) `code` (default) or `kb` (a knowledge base's repository).
- `url` (String) Clone URL without credentials: `https://…`, `ssh://…` or `git@host:org/repo.git` (`http://`, `git://`, `file://` and local paths only in development mode). Required unless `clone_policy` is `manual`.

### Read-Only

- `id` (String) The repository ID.

## Import

Import is supported using the following syntax:

```shell
# <space_id>/<repository_id or name>
terraform import spaceman_space_repository.api spc_01j0000000000000000000000/api
```

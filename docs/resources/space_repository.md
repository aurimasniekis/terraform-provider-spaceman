# spaceman_space_repository (Resource)

A repository of a space (`/spaces/{id}/repositories`, ADR-0044): its folder in the space folder, clone URL, default branch, role and clone policy. The space's node clones it (with an `auto` policy as soon as it holds the space's lease) using its own Git authentication, or with an SSH key SpaceMan holds (`ssh_key`, SpaceMan ADR-0057): the URL never carries credentials. Writer worktrees, knowledge bases and relocation use the configured repositories. The node's report (remote, heads, last fetch, changes, unpushed commits, worktrees) and syncs are runtime state and are not managed. Destroying the resource removes the repository from the space's list only: its folder on the node and the upstream repository stay; a repository a knowledge base uses cannot be removed.

## Example Usage

```terraform
# The API service, cloned by the space's node as soon as it holds the lease. The node's own Git authentication (SSH key,
# credential helper, Hallpass Git role) is used; the URL carries no credentials.
resource "spaceman_space_repository" "api" {
  space_id       = spaceman_space.payments.id
  name           = "api"
  path           = "repos/api"
  url            = "git@github.com:example-org/payments-api.git"
  default_branch = "main"
  description    = "Settlement and refunds API"
}

# A knowledge base's repository, cloned the first time a KB session needs it.
resource "spaceman_space_repository" "kb" {
  space_id     = spaceman_space.payments.id
  name         = "payments-kb"
  path         = "repos/payments-kb"
  url          = "https://github.com/example-org/payments-kb.git"
  role         = "kb"
  clone_policy = "on_demand"
}

# A private repository cloned with an SSH key SpaceMan holds: agents never receive it, and Terraform only sees the
# public half, which becomes a read-only deploy key on GitHub (integrations/github provider). github.com's host keys are
# built in; other hosts need known_hosts.
resource "spaceman_space_repository" "ledger" {
  space_id = spaceman_space.payments.id
  name     = "ledger"
  url      = "git@github.com:example-org/ledger.git"
  ssh_key  = true
}

resource "github_repository_deploy_key" "ledger" {
  repository = "ledger"
  title      = "SpaceMan (payments)"
  key        = spaceman_space_repository.ledger.ssh_public_key
  read_only  = true
}
```

## Schema

### Required

- `name` (String) Unique in the space: 1-63 lowercase letters, digits, `.`, `_` or `-`. Changing it replaces the repository.
- `space_id` (String) The space (not archived).

### Optional

- `clone_policy` (String) `auto` (default with a URL: cloned while the node holds the space's lease), `on_demand` (cloned when a run needs it or on a sync) or `manual` (default without a URL: never cloned by SpaceMan).
- `default_branch` (String) The branch the node checks out and reports on (default `main`).
- `description` (String) Description.
- `git_key_id` (String) A shared Git SSH key (`spaceman_git_ssh_key`, SpaceMan ADR-0058) the node clones and fetches with, instead of the repository's own key: SSH URLs only, the space must be allowed to use it, and `ssh_key` must not be `true`. `""`: none.
- `known_hosts` (String) known_hosts lines pinning the Git host's SSH keys, used with `ssh_key`. Empty: SpaceMan's built-in pins (github.com).
- `path` (String) Folder relative to the space folder (default the name), for example `repos/api`; not in `instances/`, `worktrees/`, `work/` or `dreams/`. Changing it replaces the repository (the old folder stays on the node).
- `role` (String) `code` (default) or `kb` (a knowledge base's repository).
- `ssh_key` (Boolean) `true`: SpaceMan holds an SSH key for this repository and the node clones and fetches with it (SSH URLs only); add `ssh_public_key` to the Git host as a read-only deploy key. `false`: no SpaceMan key (the node's own Git authentication). Unset: not managed. Agents never receive the private key, and Terraform never sees it.
- `ssh_key_version` (Number) Change this number to rotate the SSH key: SpaceMan replaces it at once, so update the host's deploy key in the same apply.
- `url` (String) Clone URL without credentials: `https://…`, `ssh://…` or `git@host:org/repo.git` (`http://`, `git://`, `file://` and local paths only in development mode). Required unless `clone_policy` is `manual`.

### Read-Only

- `id` (String) The repository ID.
- `ssh_key_fingerprint` (String) The SSH key's SHA256 fingerprint; empty without a key.
- `ssh_public_key` (String) The SSH key's public half (authorized_keys format), for the Git host's deploy key; empty without a key.

## Import

Import is supported using the following syntax:

```shell
# <space_id>/<repository_id or name>
terraform import spaceman_space_repository.api spc_01j0000000000000000000000/api
```

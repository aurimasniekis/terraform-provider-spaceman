# spaceman_dream (Resource)

A dream configuration of a space (`/spaces/{id}/dreams`): which role memories a dreamer consolidates, from which transcripts, how often and within which bounds. Dream runs are runtime state and are not managed. SpaceMan has no API to delete a configuration: destroying the resource disables it and removes it from Terraform's state.

## Example Usage

```terraform
resource "spaceman_dream" "nightly" {
  space_id       = spaceman_space.payments.id
  slug           = "nightly"
  name           = "Nightly consolidation"
  space_role     = spaceman_space_role.dreamer.name # a role whose template is of kind dreamer
  memory_roles   = ["implementor-backend"]
  interval_hours = 24
}
```

## Schema

### Required

- `name` (String) Display name.
- `slug` (String) Identifier in the space (2-31 characters). Fixed after creation.
- `space_id` (String) The space.
- `space_role` (String) A space role whose template is of kind `dreamer`.

### Optional

- `enabled` (Boolean) Whether the configuration is scheduled (default `true`).
- `include_own` (Boolean) Also read the dreamer's own transcripts (default `false`).
- `instructions` (String) Extra instructions for the dreamer.
- `interval_hours` (Number) Hours between scheduled dreams (0-720; 0, the default, runs only manually).
- `max_bytes` (Number) Transcript bytes offered per dream (64 KiB-64 MiB, default 2 MiB).
- `max_files` (Number) Transcript files offered per dream (1-200, default 20).
- `max_minutes` (Number) Time limit of one dream (5-240, default 30).
- `max_tokens` (Number) Token budget given to the dreamer (not enforced by SpaceMan).
- `memory_roles` (List of String) Role memories the dream consolidates; `*` (default) for every role.
- `transcript_roles` (List of String) Roles whose transcripts it may read; `*` (default) for every role.

### Read-Only

- `id` (String) The dream configuration ID.

## Import

Import is supported using the following syntax:

```shell
# <space_id>/<dream_id>
terraform import spaceman_dream.nightly spc_01j0000000000000000000000/drm_01j0000000000000000000000
```

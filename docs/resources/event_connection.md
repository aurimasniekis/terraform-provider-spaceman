# spaceman_event_connection (Resource)

A Pulse connection (`/event-connections`). The `.creds` content is write-only: sealed by SpaceMan, never returned and never stored by Terraform (requires Terraform 1.11 or later). Deleting is refused while a subscription uses the connection.

## Example Usage

```terraform
variable "pulse_creds" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "spaceman_event_connection" "pulse" {
  name = "pulse-prod"
  url  = "tls://pulse.example.com:4222"

  creds_wo         = var.pulse_creds
  creds_wo_version = 1
}
```

## Schema

### Required

- `creds_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The `.creds` file content issued by Pulse (write-only). Sent on create and whenever `creds_wo_version` changes.
- `name` (String) Unique name: lowercase letters, digits and dashes (2-63).
- `url` (String) `nats://host:port` or `tls://host:port`.

### Optional

- `ca_pem` (String) A PEM CA certificate for `tls://` (not secret, but never returned: the API reports only `has_ca`).
- `creds_wo_version` (Number) Change this number to send `creds_wo` again (rotation). Terraform never stores the write-only value, so it cannot see when the value itself changes.
- `enabled` (Boolean) Whether subscriptions on the connection consume (default `true`).
- `stream` (String) The JetStream stream (default `EVENTS`).

### Read-Only

- `client_id` (String) The Pulse client the credentials belong to (from the JWT).
- `has_ca` (Boolean) Whether a CA certificate is stored.
- `id` (String) The connection ID.

## Import

Import is supported using the following syntax:

```shell
terraform import spaceman_event_connection.pulse ecn_01j0000000000000000000000
```

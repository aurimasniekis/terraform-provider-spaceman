# spaceman_role_template (Resource)

A role template (`GET /role-templates`, `PUT /role-templates/{id}`): the kind of run, its profile, prompt binding and skills. Spaces configure roles from templates. SpaceMan has no API to delete a template: destroying the resource only removes it from Terraform's state.

## Example Usage

```terraform
resource "spaceman_role_template" "worker" {
  slug       = "backend-worker"
  name       = "Backend worker"
  kind       = "worker"
  profile_id = spaceman_harness_profile.careful.id
  prompt_id  = spaceman_prompt.worker.id # follows the latest published version
  skills     = [{ skill_id = spaceman_skill.release_notes.id }]
}
```

## Schema

### Required

- `kind` (String) `control`, `worker`, `kb`, `dreamer` or `diagnostic`. Fixed after creation.
- `name` (String) Display name.
- `slug` (String) Unique identifier. Fixed after creation.

### Optional

- `description` (String) Description.
- `memory_conventions` (String) How the role keeps its memory.
- `profile_id` (String) The harness profile.
- `prompt_id` (String) The prompt (prompt binding).
- `prompt_pin` (String) A published version of `prompt_id`; empty follows the latest version.
- `settings` (Map of String) Harness settings overriding the profile's.
- `skills` (Attributes List) Skills the role gets. (see [below for nested schema](#nestedatt--skills))

### Read-Only

- `id` (String) The template ID.
- `revision` (Number) Increments on every change.

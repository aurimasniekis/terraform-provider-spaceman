# spaceman_approval_policy (Resource)

Makes an operation need a person's approval (`POST/DELETE /approval-policies`). Policies cannot be edited: any change removes the policy and adds a new one. Approvals it already produced stay usable until they expire or are revoked.

## Example Usage

```terraform
resource "spaceman_approval_policy" "tracker_writes" {
  space_id      = spaceman_space.payments.id
  operation     = "mcp.tracker.comment"
  uses          = 1
  valid_seconds = 900
  note          = "Comments on tickets need a person's approval."
}
```

## Schema

### Required

- `operation` (String) `spaceman.<tool>`, `mcp.<server>.<tool>`, or a prefix ending in `.*`.

### Optional

- `note` (String) Note shown to approvers.
- `request_ttl_seconds` (Number) How long a request waits for a decision (300-2592000, default 86400).
- `space_id` (String) The space; empty (default) applies to every space.
- `uses` (Number) Executions one approval allows (1-100, default 1).
- `valid_seconds` (Number) How long an approval can be used after the decision (60-604800, default 3600).

### Read-Only

- `id` (String) The policy ID.

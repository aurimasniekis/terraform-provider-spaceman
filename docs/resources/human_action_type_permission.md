# spaceman_human_action_type_permission (Resource)

Who may see, create and respond to one human-action type in a space (SM-HUI-008, ADR-0050; `/spaces/{id}/human-type-permissions/{type}`). Roles are minimums over the space's built-in roles and only narrow the roles' own permissions (`human_action:read`, `human_action:respond`, `approval:decide`): a type without a stored permission lets viewers see, operators create and respond, and any agent ask. Changing a permission needs `human_type_permission:write` (space or global admins) and is audited. Creating a permission that already exists fails (import it). Destroying the resource deletes the permission; the defaults apply again. Fields left out start from the defaults and are not owned afterwards.

## Example Usage

```terraform
# Only operators see approvals in the payments space, only admins decide them, and only deployer agents may ask.
resource "spaceman_human_action_type_permission" "approvals" {
  space_id     = spaceman_space.payments.id
  action_type  = "approval"
  view_role    = "operator"
  respond_role = "admin"
  agents       = "roles"
  agent_roles  = ["deployer"]
}

# A custom type: name it by its ID. Only admins may ask people with it; agents may not.
resource "spaceman_human_action_type_permission" "deploy_window" {
  space_id    = spaceman_space.payments.id
  action_type = spaceman_human_action_type.deploy_window.id
  create_role = "admin"
  agents      = "none"
}
```

## Schema

### Required

- `action_type` (String) `question`, `approval`, `todo`, `message`, or a custom type's ID (`hty_…`, preferably `spaceman_human_action_type.<name>.id`) or slug.
- `space_id` (String) The space.

### Optional

- `agent_roles` (Set of String) Space roles whose agents may ask when `agents` is `roles` (at least one then; empty otherwise).
- `agents` (String) Which agents may ask with the type: `any` (default), `roles` (only `agent_roles`) or `none`.
- `create_role` (String) Weakest role that may ask people with the type: `operator` (default) or `admin`.
- `respond_role` (String) Weakest role that may respond, assign, comment, clarify, move or cancel: `operator` (default) or `admin`.
- `view_role` (String) Weakest role that sees actions of the type: `viewer` (default), `operator` or `admin`.

### Read-Only

- `id` (String) `<space_id>/<action_type>`.
- `type_slug` (String) A custom type's slug (empty for built-in types).

## Import

Import is supported using the following syntax:

```shell
# <space_id>/<action_type> (a built-in type, or a custom type's ID)
terraform import spaceman_human_action_type_permission.approvals spc_01j0000000000000000000000/approval
```

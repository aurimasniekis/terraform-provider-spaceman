# spaceman_human_action_policy (Resource)

A human-action policy (SM-HUI-008, ADR-0032): reminders, escalation, rate limits and response routing for one action type, as an installation default (`PUT/DELETE /human-policies/{type}`) or a space override (`/spaces/{id}/human-policies/{type}`). The most specific policy applies as a whole (space and type, space and `all`, default and type, default and `all`, built-in). Fields the configuration leaves out start from the policy in force for that type when the resource is created and are not owned afterwards. Creating a policy that already exists fails (import it). Destroying the resource deletes the policy; the next less specific one applies. Pending actions get their reminder and escalation times recomputed on every change. Human-action requests and responses are runtime state and are never managed.

## Example Usage

```terraform
# Installation default for approvals.
resource "spaceman_human_action_policy" "approvals" {
  action_type            = "approval"
  remind_after_minutes   = 30
  remind_every_minutes   = 120
  max_reminders          = 5
  escalate_after_minutes = 240
  escalate_priority      = "urgent"
}

# A space override for questions: keep the answer for the asking agent's next run.
resource "spaceman_human_action_policy" "payments_questions" {
  space_id          = spaceman_space.payments.id
  action_type       = "question"
  requester_ended   = "next_launch"
  hold_minutes      = 120
  successor_role    = "implementor"
  rate_per_run_hour = 10
}
```

## Schema

### Required

- `action_type` (String) `question`, `approval`, `todo`, `message`, `custom` (every custom type) or `all` (every type without a more specific policy).

### Optional

- `escalate_after_minutes` (Number) Escalate this long after the action was asked (0-43200; 0: never). Needs `escalate_priority` or `escalate_assignee`.
- `escalate_assignee` (String) Assign the action to this user (`usr_…`) when it escalates; `""` for nobody.
- `escalate_priority` (String) Raise the priority to this on escalation: `high`, `urgent` or `""` (never lowers it).
- `hold_minutes` (Number) `next_launch`: how long to wait for that run before rerouting (1-10080).
- `max_reminders` (Number) Reminders at most (1-20).
- `rate_per_run_hour` (Number) New actions of this type one agent run may ask per hour (1-1000).
- `rate_per_space_hour` (Number) New actions of this type agents of one space may ask per hour (1-10000).
- `remind_after_minutes` (Number) Remind people this long after the action was asked (0-43200; 0: no reminders).
- `remind_every_minutes` (Number) Repeat the reminder this often (0-43200; 0: once).
- `requester_ended` (String) When the requester's run has ended: `reroute` at once, or `next_launch` (keep it for the next run of the same agent instance).
- `space_id` (String) The space (not archived); empty (default) is the installation default.
- `successor_role` (String) Reroute to a live run of this role before control; `""`: control.
- `wake_idle` (Boolean) Wake an idle requester with a one-line terminal notice.

### Read-Only

- `id` (String) The policy ID (`hpl_…`).

## Import

Import is supported using the following syntax:

```shell
# <action_type> for an installation default, <space_id>/<action_type> for a space override
terraform import spaceman_human_action_policy.approvals approval
terraform import spaceman_human_action_policy.payments_questions spc_01j0000000000000000000000/question
```

# spaceman_node (Resource)

A node (`POST/GET/PUT /nodes`): a host that runs `spaceman-agent`. Creating it registers the node and returns its one-time `enrollment_token`; pass it to the host's provisioning (cloud-init, Ansible) to enroll the agent. Destroying it revokes the node (permanent: its credentials stop working, its spaces' runs stop, and its name stays taken) unless `revoke_on_destroy = false`, which only removes it from the state. Connection, capacity and agent version are runtime state: read them with the `spaceman_node` data source.

## Example Usage

```terraform
resource "spaceman_node" "build" {
  name        = "build-01"
  description = "CI build host"
  labels      = { zone = "eu" }

  # Bump to issue a new enrollment token, for example when the host is rebuilt.
  enrollment_version = 1
}

# Hand the one-time token to the host's provisioning, which runs:
#   spaceman-agent enroll --token <token>
# The token works once and expires after nodes.enrollment_ttl (24 hours by default).
resource "local_sensitive_file" "build_enroll" {
  filename        = "${path.module}/build-01.enroll"
  content         = spaceman_node.build.enrollment_token
  file_permission = "0600"
}

resource "spaceman_space" "payments" {
  slug    = "payments"
  name    = "Payments"
  node_id = spaceman_node.build.id
}
```

## Schema

### Required

- `name` (String) Lowercase DNS-like name, unique (letters, digits, dashes; at most 63).

### Optional

- `description` (String) Description.
- `enabled` (Boolean) `false` disables the node: it gets no new runs and its connection is closed. Default `true`. A node that has not enrolled yet stays `pending` either way.
- `enrollment_version` (Number) Change this number to issue a new enrollment token, for example to rebuild the host. Using the new token re-enrolls the node and replaces its credentials; the old token stops working.
- `labels` (Map of String) Labels (at most 32; keys are lowercase names, values at most 128 bytes).
- `revoke_on_destroy` (Boolean) On destroy, revoke the node (default `true`). `false` only removes it from the Terraform state.

### Read-Only

- `enrollment_expires_at` (String) When `enrollment_token` expires (RFC 3339; SpaceMan's `nodes.enrollment_ttl`, 24 hours by default).
- `enrollment_token` (String, Sensitive) The one-time enrollment token: run `spaceman-agent enroll --token …` on the host with it before it expires. Set on create and whenever `enrollment_version` changes; empty after an import. It is stored in the Terraform state (sensitive): it works once, and only until `enrollment_expires_at`.
- `id` (String) The node ID (`nod_…`).
- `state` (String) `pending` (not enrolled yet), `active` or `disabled`.

## Import

Import is supported using the following syntax:

```shell
# A node by its ID. The enrollment token is not imported (SpaceMan shows it only once); bump enrollment_version to issue a new one.
terraform import spaceman_node.build nod_01hq3j5k7m9p2r4t6v8x0z2b4d
```

# spaceman_oidc_group_mapping (Resource)

Maps a groups-claim value of an OIDC provider to a role in a domain (`POST/DELETE /oidc/providers/{id}/mappings`). Applied at every SSO sign-in; SSO grants apply only to SSO sessions. Mappings cannot be edited: any change replaces the mapping.

## Example Usage

```terraform
resource "spaceman_oidc_group_mapping" "admins" {
  provider_id = spaceman_oidc_provider.porch.id
  group_value = "spaceman-admins"
  role        = "admin"
  domain      = "*"
}
```

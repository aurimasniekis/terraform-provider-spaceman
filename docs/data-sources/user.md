# spaceman_user (Data Source)

A user, by ID or email (`GET /users`), for example one created by OIDC just-in-time provisioning whose grants `spaceman_user_grants` manages, or an escalation assignee of `spaceman_human_action_policy`. Nothing secret is read.

## Example Usage

```terraform
# A user created by OIDC just-in-time provisioning.
data "spaceman_user" "grace" {
  email = "grace@example.com"
}

resource "spaceman_user_grants" "grace" {
  user_id = data.spaceman_user.grace.id
  grant   = [{ role = "operator", domain = spaceman_space.payments.id }]
}
```

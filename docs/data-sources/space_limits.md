# spaceman_space_limits (Data Source)

A space's effective limits (`GET /spaces/{id}/limits`): every limit's value in force, the installation default, the space's own override and where the value comes from (`installation`, `space` or `queue_policy`). Budgets are usage-based and reported late, never a hard currency limit.

## Example Usage

```terraform
data "spaceman_space_limits" "payments" {
  space_id = spaceman_space.payments.id
}

output "payments_concurrency" {
  value = data.spaceman_space_limits.payments.values["max_concurrent_runs"]
}
```

## Schema

### Required

- `space_id` (String) The space.

### Read-Only

- `limits` (Attributes List) Every limit, in SpaceMan's display order. (see [below for nested schema](#nestedatt--limits))
- `on_lower` (String) What lowering the concurrent-runs limit does to running runs: `drain` or `stop`.
- `overrides` (Map of Number) The space's own overrides, by key (set in the UI, the API or `spaceman_space_limits`).
- `values` (Map of Number) The effective value of every limit, by key.
